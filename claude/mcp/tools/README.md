# أدواتك الخاصة لـ Claude Code (بلغة بايثون)

كل ملف `.py` في هذا المجلد يُحمَّل تلقائياً عند بدء كل جلسة Claude Code. كل دالة عليها `@tool` تصبح أداة يستطيع Claude استدعاءها، وتظهر باسم `mcp__allinone__<اسم الدالة>`.

## مثال

```python
from mcp_kit import tool

@tool
def word_count(text: str) -> str:
    """عدّ الكلمات في نص."""
    return str(len(text.split()))
```

- **الوصف**: نص الـ docstring هو ما يقرؤه Claude ليقرر متى يستخدم الأداة، فاكتبه بوضوح.
- **أنواع المعاملات**: تتحول تلقائياً إلى مخطط JSON، والأنواع المدعومة هي `str` و`int` و`float` و`bool` و`list` و`dict`.
- **المعاملات الاختيارية**: أي معامل له قيمة افتراضية يصبح اختيارياً.
- **ما ترجعه الدالة**: يُرسل إلى Claude. النص يُرسل كما هو، وأي شيء آخر يُحوَّل إلى JSON.
- **الأخطاء**: أي استثناء يُعرض على Claude كرسالة خطأ ولا يوقف الخادم.
- **تعطيل ملف**: ابدأ اسمه بـ `_` حتى لا يُحمَّل، مثل `_draft.py`.
- **تطبيق التغييرات**: أعد تشغيل Claude Code بعد أي تعديل.

## نصائح

- لا تطبع شيئاً على stdout، لأنه مخصص لبروتوكول MCP. استخدم `from mcp_kit import log` للطباعة على stderr.
- الأدوات المدمجة (الذاكرة و`ask_model` وغيرها) موجودة في `../allinone_tools.py`، ويمكنك تعديلها أيضاً.
- لإضافة خادم MCP كامل من طرف آخر (مثل GitHub أو قاعدة بيانات)، أضفه في `config/mcp.jsonc`.
